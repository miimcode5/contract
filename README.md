# سازنده قرارداد طراحی — قلموم (Ghalamoom Contract Builder)

نسخهٔ آنلاینِ «سازنده قرارداد طراحی» قلموم: نوع قرارداد را انتخاب کنید، اطلاعات را پر کنید، بندها را ویرایش کنید و خروجی **PDF / Word** حرفه‌ای با لوگوی شخصی بگیرید.

🔗 **نسخهٔ آنلاین:** https://miimcode5.github.io/contract/

## امکانات

- 🧙 **ویزارد ۴ گامه** — انتخاب نوع قرارداد ← اطلاعات طرفین و پروژه ← ویرایش بندها ← پیش‌نمایش و دانلود
- 📝 **۱۰ نوع قرارداد** — لوگو، هویت بصری، فونت، بسته‌بندی، پوستر و بنر، کاتالوگ و بروشور، رابط کاربری، تصویرسازی، موشن‌گرافیک، ست اداری
- 🔤 مبتنی بر نمونه قرارداد **انجمن صنفی طراحان گرافیک ایران** (۱۰ مادهٔ استاندارد)
- ✏️ ویرایش کامل بندها — عنوان، متن، روشن/خاموش، حذف، جابه‌جایی و افزودن بند جدید
- 👁️ **پیش‌نمایش زندهٔ A4** هم‌زمان با تایپ
- 🖨️ خروجی **PDF** (چاپ مستقیم با `@page: A4`) و **Word** (فایل `.doc` قابل ویرایش)
- 🖼️ افزودن **لوگوی شخصی** در فوتر سند
- 💾 **ثبت واقعی قرارداد در Supabase** (درج-فقط؛ بدون دسترسی خواندن برای عموم — RLS)
- 📬 عضویت خبرنامه با ذخیرهٔ ایمیل در Supabase
- 🌙 پوستهٔ تیره/روشن، جستجوی قراردادها، دستیار هوشمند (چت)، شمارش‌معکوس جشنواره
- 📱 طراحی واکنش‌گرا و RTL کامل با فونت **وزیرمتن** (self-hosted)

## تکنولوژی

استاتیک خالص — HTML/CSS/JS بدون هیچ وابستگی یا مرحلهٔ build. نمایش زنده با GitHub Pages و **GitHub Actions** (`.github/workflows/deploy.yml`).

## اجرای محلی

```bash
# هر سرور استاتیکی کافی است، مثلاً:
npx serve .
# یا
python3 -m http.server 8080
```

## دیپلوی (GitHub Actions → GitHub Pages)

هر push روی شاخهٔ `arena/37e84770-contract` یا `main` باعث بیلد و انتشار خودکار می‌شود:

1. `actions/checkout` → `configure-pages` → `upload-pages-artifact` (path: ریشهٔ مخزن) → `deploy-pages`
2. آدرس نهایی: `https://<user>.github.io/<repo>/` (هم‌اکنون برای `miimcode5/contract` فعال است)

## Supabase

پروژهٔ اختصاصی `ghalamoom-contract` — دو جدول با RLS و سیاستِ **درج-فقط برای `anon`** (بدون `SELECT` برای عموم):

| جدول | کاربرد |
|---|---|
| `contracts` | ثبت نسخهٔ نهایی قرارداد (ورودی‌های فرم + بندهای نهایی + لوگو) |
| `newsletter_subscribers` | ایمیل‌های عضویت خبرنامه |

کلید مرورگر از نوع **publishable** است و فقط با RLS کار می‌کند. کلید مخفی هرگز در مخزن قرار نمی‌گیرد.

## ساختار مخزن

```
index.html               # صفحهٔ اصلی (تمام بخش‌ها)
assets/css/style.css     # سیستم طراحی (تیره/روشن، RTL)
assets/js/app.js         # منطق ویزارد، بندها، پیش‌نمایش، خروجی‌ها، Supabase
assets/fonts/            # وزیرمتن (self-hosted woff2)
favicon.svg · robots.txt · sitemap.xml
.github/workflows/deploy.yml
```

> ⚠️ این ابزار جایگزین مشاورهٔ حقوقی نیست. برای پروژه‌های پیچیده با وکیل مشورت کنید.
